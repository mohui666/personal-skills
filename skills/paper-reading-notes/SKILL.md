# 论文阅读与笔记

用同一套格式完成论文阅读、方法讲解和按需保存笔记。默认中文，先让读者理解论文解决什么问题，再讲清方法如何工作。

## 按用户要求选择工作范围

- **阅读与讲解（默认）**：用户提供论文标题、链接、编号、PDF、正文，或上下文已确定论文时，直接阅读并输出完整讲解，不再询问先看摘要还是方法。采用 [统一阅读与笔记格式](references/note-format.md)。
- **单项追问**：用户只问某个概念、公式、模块或实验时，集中回答该问题；不重复整篇报告。要求重新总结时再整合为固定格式。
- **项目启示（按需）**：只有用户要求“对项目的启示”“如何借鉴”“结合我的项目”等时，才新增“项目思考”。仅处在某个项目目录，不代表需要分析该项目。
- **保存或整理（按需）**：只有用户要求保存、更新、整理成笔记或统一已有笔记时，才修改笔记文件。阅读、项目分析和保存可以在同一次请求中组合完成；单纯格式整理不自动重读全部论文。

论文尚未确定时，先利用当前对话与用户给定材料定位；存在会改变结论的同名歧义才集中澄清。用户当次指定的语言、篇幅、章节和输出位置优先于默认格式。

## 阅读原文并确定依据

- 优先使用用户提供的原文；需要查找时读取出版方、arXiv 或作者提供的原论文，不能仅凭搜索摘要、标题、旧笔记或记忆解释完整方法。优先沿用用户指定版本，记录实际读到的版本。
- 完整阅读讲解应覆盖摘要、问题背景、方法、关键实验和局限；附录按理解关键机制的需要补读。涉及结构图、公式或表格时核对对应原文位置，解析不清楚时查看相应页面。
- 只拿到摘要、片段或无法访问全文时，明确阅读范围，给出已有材料支持的部分；未读到的方法和实验标为“当前材料未覆盖”，不补造细节或宣称完成全文阅读。
- 仅在用户关注实现，或关键机制需要代码核对时检查官方实现，并记录所读版本或提交。论文描述、代码实际覆盖和本地运行结果分别表述；读代码不等于已复现。
- 保存作者、年份、来源和版本等已知信息，未知内容不猜。关键结论、数字、公式和设计应就近关联原文章节、图表或来源链接。

## 讲清方法与解释

按模板输出“摘要 → 核心方法 → 阅读追问与概念解释 → 实验结果与边界”。方法是主体，不能只罗列模块名或复述摘要。

- 用输入、处理和输出串起整条方法；逐个说明关键设计解决的障碍、实际操作、产物以及如何连接下一步。区分模型、外部工具、后处理和执行环节，避免把已有基础组件全部称作创新。
- 对学习方法，分清训练与推理：训练数据和监督目标从哪里来，损失约束什么，哪些参数更新或冻结，推理如何使用已学能力。对于理论、综述或非学习方法，改用适合的推导、研究设计、检索筛选或求解流程，不硬套训练框架。
- 解释必要公式时，先说它在算什么，再区分输入、已知目标、网络输出和可训练参数。更新式讲清“旧状态 → 本步计算 → 新状态”；循环中分清样本编号、网络层、生成步与现实时间。
- 用一个具体例子贯穿方法。教学类比、假设数值和简化推导要明确标注；数值可核算，省略的条件、缩放或掩码就近交代，不能写成论文实验或原作者公式。
- 用户说“没懂”“举个例子”时，先用一句直白解释和具体例子，再补术语或公式；方法不可缺少的解释留在对应步骤，避免两个章节重复同一段内容。
- 默认提供完整中文摘要，覆盖原摘要中的研究背景、问题、关键方法、主要结果和结论，保留重要数字、比较对象和限定条件。按信息量自然分段，不限制为一句话或一小段；“一句话概括”仅为可选导读，不能替代完整摘要。
- 完整摘要优先以论文 Abstract 为依据，按实际内容与引用要求准确标注“原文翻译”或“完整阅读整理”，自行整理不得冒充原摘要。未拿到原摘要时，可依据已读正文提供完整阅读整理并说明来源限制。英文摘要按用户要求提供，已有笔记中的英文内容继续保留。

实验数字要保留任务、数据、对照、单位和适用条件。相对增幅与百分点不能混写，视频质量、仿真成功率和实机成功率不能互相替代。区分作者报告的结果、作者承认的局限与自己的推断；失败或不支持主张的结果也要保留。

## 按需分析项目启示

先确认用户所指项目及关注的问题，利用当前对话和必要的项目文件核实目标、输入输出、约束与已有能力。不要仅凭旧记忆、README 愿景或项目名称认定某功能已经实现；无法核实的部分明确写成假设。

按模板逐条写“项目问题 → 论文机制 → 适配方案 → 前提与代价 → 最小验证 → 局限”。只给有具体对应关系的启示，不为凑数量泛泛提出引入世界模型、强化学习等建议；证据不足时说明不能直接迁移的原因。项目建议与论文结论分开，不把建议写成已实现、已验证，也不自动开始改代码或运行实验。

## 按需保存和整理笔记

- 先找当前项目的笔记目录、目录页和同论文文件，沿用已有文件名。一篇论文一份 Markdown；把新解释合并到相应位置，不把多轮回答原样堆在末尾。
- 当前项目采用“笔记/论文、笔记/README.md、笔记/资料来源.md”时继续沿用，并同步本次相关条目。没有既定位置且用户未指定时，默认使用当前项目的“笔记/论文”；不绑定本机某个项目的绝对路径。
- 新建或统一格式使用同一份 [格式规范](references/note-format.md)。局部补充只改相关内容，不顺带重排整篇。保留已有公式、追问、实验边界、项目思考、英文摘要和来源；本次未要求新增可选章节，不代表删除已有内容。
- 批量统一格式先盘点目标并保存可恢复原稿，包含未提交和未跟踪内容。保留文件名、原整理日期、来源锚点与有效链接；只有标题变更实际影响片段链接时，才同步对应引用。
- 使用已有资料来源索引的相对链接与稳定锚点；新增来源补到对应索引，纯重排不制造新的来源记录。用户表示“懂了”不等于自测通过，不自动勾选全部自测。

## 完成前核对

先核对阅读范围、摘要完整度、方法链条、公式与实验条件，以及是否混淆论文事实、教学解释、项目建议和运行证据。确认没有擅自增加项目分析或文件写入。

写入文件时，检查本次涉及的全部文件：正文有无遗失、公式是否等价、数值是否正确、围栏是否闭合、标题和表格是否可读、本地链接和来源锚点是否有效。批量重排比较修改前后的内容；公式换排版单独核对符号、正负号和下标。

仅交付本次要求的内容。保存后提供实际文件链接与必要的未解决问题；纯格式整理不声称重新验证论文结论。
